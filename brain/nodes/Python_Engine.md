# Python Engine

Motor computacional em Python 3.14+ que alimenta o [[ThSyr]].

## Sinapses
- Conectado a [[Cortex_Central]] e [[ThSyr]].
- Executa a gestao de memorias e interface CLI em `thsyr.py`.
- Opera o [[Continuous_Runtime]], [[Model_Gateway]], [[Executive_System]], [[Tool_Bus]] e [[Hybrid_Retrieval]].
- Opera a rotina de consolidacao noturna e geracao de grafo neural em SVG e PNG.
- Projetado para operar localmente na maquina de [[Operador]].
