## Conceito Central

Modelagem relacional, SQL e persistência de dados estruturados, cobrindo fundamentos de modelagem relacional e SQL avançado para aplicações corporativas.

## Tópicos Cobertos

- **Modelagem relacional** — entidades, relacionamentos, normalização (1FN, 2FN, 3FN)
- **SQL básico** — SELECT, INSERT, UPDATE, DELETE
- **SQL avançado** — JOINs, subqueries, triggers, stored procedures
- **Modelagem visual** — diagramas conceituais e lógicos de schema relacional
- **Scripts SQL** — criação de schemas, migrations e indexação

## Práticas e Aplicações

- Modelagem de schemas normalizados e views analíticas.
- Estruturação de consultas de alta performance com índices b-tree e chaves estrangeiras.
