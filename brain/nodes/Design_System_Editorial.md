# Design System Editorial Botanico

Linguagem visual sofisticada e acolhedora de padrao editorial botanico.

## Sinapses
- Conectado a [[Cortex_Central]], [[Design_Editorial]], [[Operador]].

## Identidade Cromatica
- Marinho Profundo (#0D152D / #141A3C)
- Marsala Peonia (#78112C / #781B3A)
- Ouro / Latao Nobre (#CCA43B / #C6AC46)
- Marfim / Creme (#FBF4DB / #FFF5CF)
- Verde Salvia / Folhagem (#6E8268 / #7B896D)
- Terracota (#B86645)

## Regras
- Tipografia: Cormorant Garamond / Cinzel / Iowan Old Style para titulos; Plus Jakarta Sans / Inter para interface.
- Icones: 48x48, traco 1.4-1.6px, pontas suaves, funcionais apenas.
- Liquid Glassmorphism com borda de luz e arcos editoriais.
